MongoDB NoSQL Database Project

Introduction

MongoDB is a NoSQL database that stores data in flexible JSON-like documents.
It is widely used for applications that require flexible and scalable data storage.

Objectives

- To understand the concept of NoSQL databases.
- To learn the basic features of MongoDB.
- To create a database and collection.
- To perform CRUD operations.
- To manage student data using MongoDB.

Database Details

Collection Name: Students
